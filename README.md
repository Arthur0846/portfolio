# Portfólio

Site pessoal de Arthur Schmidt Lorentz, estudante de Sistemas de Informação
na UFSM. Reúne quem eu sou, o que estudo, no que tenho trabalhado e como falar
comigo.

## O que tem no site

- Apresentação, formação e um terminal interativo: basta digitar o nome de uma
  seção e pressionar Enter para ir até ela.
- Seções sobre mim, projetos, habilidades e experiência.
- Formulário de contato que valida os campos e completa o endereço a partir do
  CEP usando a API pública do ViaCEP.
- Laboratório com chamadas a uma API pública: leitura e criação de postagens,
  com um gráfico sobre os dados retornados.

## Tecnologias

O front-end usa Next.js com React e TypeScript, e a estilização fica com o
Tailwind CSS. O gráfico do laboratório é desenhado com o Chart.js.
